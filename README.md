# CLS Logger v3.0.0

Standalone log viewer for 7 Days to Die. No mod installation required.

## Features

- Real-time game log monitoring
- Auto-detection of current log file
- External log viewer for analyzing any log files
- Mod detection with source filtering
- Advanced filtering by type, source, mod, or text search
- Favorites system
- Export to TXT, Excel, XML
- Smart hints for common errors
- Spam and exclude filters
- Dark modern UI

## Installation

Download the latest release, extract, and run `CLS Logger.exe`.

## Configuration

Config files are created automatically in the `config` folder on first launch:
- `CustomHints.xml` — Custom hints for specific errors
- `SpamFilters.xml` — Spam message grouping rules
- `ExcludeFilters.xml` — Log lines to ignore
- `ModTags.xml` — Custom mod detection tags

## Requirements

- Windows 10/11 64-bit
- 7 Days to Die (any version)
